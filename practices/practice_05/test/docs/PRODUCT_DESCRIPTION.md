# ОПИСАНИЕ ПРОДУКТА

Цель
Минимальный бэкенд кофейни с валютой CoffeeCoin, новостями, скидками, mock-оплатой и лояльностью.

Аудитория
- Customers, Baristas, Admins для учебных сценариев

Основные фичи
- Управление меню: название, состав, размеры, цена в CoffeeCoin, калории
- Новости: локальные/in-memory записи
- Заказы и mock-оплата: создание заказа, оплата
- Скидки: детерминированная «скидка дня» и happy hour; применяется максимум
- Время работы/статус: по умолчанию 08:00–20:00, с параметром для тестов
- Состав и стоимость: детали по позиции, включая калории и цену

Дополнительные фичи
- Лояльность: 1 балл за целый CoffeeCoin трат
- Отзывы: рейтинг 1–5 и комментарии по позиции меню

Тон сообщений об ошибках
- Дружелюбный и точный: «Позиция меню не найдена», «Недопустимый menuId»
