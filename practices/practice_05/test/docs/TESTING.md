# Тестирование

Запуск
- Тесты: `pytest -q`
- Бенчмарки: `pytest -q -k bench --benchmark-only`

Покрытие
- Health/Ready: базовые проверки работоспособности
- Меню: CRUD, детали
- Новости: список/создание
- Статус: расписание, открыт/закрыт с параметром времени
- Скидки: детерминированная скидка дня, happy hour
- Заказы: создание с учётом скидок, оплата, получение статуса
- Лояльность: накопление баллов
- Отзывы: добавление и выборка

Бенчмарки
- GET /api/v1/menu/
- GET /api/v1/discounts/current
- POST /api/v1/orders/

 Маркер
- Используется `@pytest.mark.benchmark`; селектором групп управляет -k bench
