# Menu Management

## Why
- Управлять витриной напитков и десертов: добавление, обновление, удаление позиций, просмотр деталей состава и калорий.

## How
- Модели `MenuItemIn/MenuItem`; in‑memory репозиторий с авто‑инкрементом id
- Роуты `/api/v1/menu` для CRUD; `/{id}/details` для состава/калорий/цен
- Публичный каталог `/api/menu` с фильтрами `category`, `sort=price|popularity`, поиском `q`

## What follows
- Персистентность (SQLite) при масштабировании
- Роли и права (Admin) для модификаций; расширение фильтров и тегов
