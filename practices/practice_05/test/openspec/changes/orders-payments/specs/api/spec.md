## ДОБАВЛЕНО: Заказы и Оплата

### Требование: создание заказа
- POST /api/v1/orders с items [{menuId, quantity}] считает сумму со скидками и возвращает 201

### Требование: оплата заказа
- POST /api/v1/orders/{id}/pay помечает заказ как paid

### Требование: получение заказа
- GET /api/v1/orders/{id} возвращает заказ
