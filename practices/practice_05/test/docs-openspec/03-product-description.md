## Бизнес-логика
- Меню: CRUD, детали (ingredients, calories, prices)
- Новости: список и создание, сортировка по createdAt desc
- Заказы: расчёт суммы, скидки (daily/happy hour), статусы created/paid
- Скидки: deterministic скидка дня, happy hour 14:00–16:00; применяется максимум
- Статус магазина: дефолт 08:00–20:00, параметр now для тестов
- Лояльность: 1 балл за целый CoffeeCoin при customerId
- Отзывы: добавление и выборка по menuId

## Аудитория
- Customers, Baristas, Admins (операции админа через /api/v1)

## Сценарии
- Просмотр меню и деталей, фильтры/поиск на публичном `/api/menu`
- Создание заказа и оплата (mock), просмотр статуса
- Просмотр скидок и статуса магазина
- Чтение/создание новостей
- Начисление баллов лояльности
- Добавление отзыва
