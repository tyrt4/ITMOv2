## Дизайн-система
- Палитра: #00704A (primary), #D4E9E2 (bg), #F1F8F6 (surface), #1E3932 (text)
- Типографика: Playfair Display (h1/h2), Inter (body)

## Компоненты
- Header, Footer
- MenuCard (name, price, calories, category, popularity)
- NewsCard (title, createdAt)
- CartDrawer (items, total)
- StatusBadge (open/closed)

## Состояния
- loading / empty / error / success для каждой страницы

## Адаптивность
- breakpoints: 640 / 768 / 1024 / 1280
- Grid карточек: 1/2/3/4 колонки

## Доступность
- Контраст и фокус-стили, aria‑label для кнопок, семантические элементы
