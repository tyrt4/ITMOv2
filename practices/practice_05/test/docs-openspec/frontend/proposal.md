## Why
- Предоставить минимальный UI для витрины: меню, новости, скидки, корзина/чекаут, статус магазина

## How
- Статический фронтенд, смонтированный под `/ui/`, использует публичные API `/api/*`
- Компонентный подход: Header, Footer, MenuCard, NewsCard, CartDrawer, StatusBadge

## What follows
- Перенос в React/Vite при необходимости, добавление аккаунта и отзывов в UI
