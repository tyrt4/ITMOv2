## Why
- Нужен простой, воспроизводимый API для учебных сценариев кофе‑магазина
- Ценность: быстрые итерации, понятные контракты, локальный запуск без внешних сервисов

## How
- FastAPI с in‑memory репозиториями, авто‑OpenAPI
- Разделение `/api/v1/*` (админ/внутреннее) и публичных алиасов `/api/*`
- Модели: MenuItem, NewsItem, Order, Review, Loyalty
- Скидки: daily deterministic (seed по дате) и happy hour 14:00–16:00 (берём максимум)

## What follows
- Потенциальная персистентность (SQLite)
- Расширение статусов заказа и правил лояльности
- Безопасность/аутентификация при выходе за рамки учебного сценария
